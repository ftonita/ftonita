# 5. Подготовка к вопросам по репозиториям

Для каждого проекта: что объяснить своими словами и где в коде ответ.

## pipeline-platform
1. **Почему генерируем child pipeline, а не `rules:` в статическом файле?** В дочернем пайплайне `CI_PIPELINE_SOURCE=parent_pipeline`, правила на merge request не работают; контекст читается в родительском job (`context.py`, `generator._plan`).
2. **Как Vault аутентифицирует CI без статического токена?** `id_tokens` (JWT) + нативный `secrets:`; роль в Vault привязана к `project_path` и `ref_protected` (README, раздел Vault).
3. **Почему тег образа = короткий SHA?** Неизменяемость и трассируемость; тег релиза добавляется отдельно (`generator._build_job`).
4. **Как версионируете без поломки потребителей?** Движущийся тег `v1`, неизменяемый `v1.x.y`, схема `platform.v1`, breaking → `v2` (`RELEASING.md`).
5. **Что не проверено?** Реальный runner, Kaniko, Nexus (README, «What is verified»).

## vault-migration-toolkit
1. **Почему отпечатки HMAC, а не хеш?** Ключ случайный на миграцию: нельзя подобрать слабый секрет по леджеру (`fingerprint.py`).
2. **Что такое CAS и зачем?** `cas=0` = create-only; параллельная запись не затирается (`backends.py`, `migrate.apply`).
3. **Как ведёт себя при частичном сбое?** Повторный запуск сравнивает с Vault и дописывает недостающее (`test_partial_failure_is_resumable`).
4. **Что в manual queue?** Всё неоднозначное: нет команды, неизвестное окружение, коллизия пути (`rules.plan`).

## access-as-code
1. **Почему `compile` выдаёт только эффективный доступ?** Просроченное и offboarded не попадёт в системы даже без lint (`compile.effective`).
2. **Разделение обязанностей через группы?** AAC007 считает роли по людям после разворачивания групп (`lint.py`).
3. **Как отличаете drift?** Сравнение desired и экспортированного снимка по четырём областям (`drift.py`). Экспорт из живых систем не реализован.

## release-bottleneck-analyzer
1. **Почему доли считаются по средним, а не медианам?** Средние аддитивны и дают 100%; медианы и p90 показаны рядом.
2. **Как отличаете медленное ревью от выходных?** `--working-hours` (`timeutil.py`).
3. **Насколько верен what-if?** Пересчёт по каждому изменению при допущении независимости стадий; это ориентир.
4. **Откуда цифры в README?** Из синтетического генератора, не измерения.

## opsbot
1. **Модель угроз?** Таблица в README: allowlist, правило двух человек, лимиты, plain text, аудит.
2. **Почему код подтверждения не сгорает при попытке неавторизованного?** `peek` перед `take` (`core._confirm`).
3. **Что если аккаунт approver угнан?** Бот не защитит; нужен 2FA в Telegram (README, «Not verified»).
